Model Rescue Simulation

Train, test, improve, and compare a small fictional model in about 20 minutes.

Overview

This is the core simulation activity. You will use made-up data only.

Reflection is submitted outside this simulation on your class worksheet.

⚠️ Critical Thinking Check

Do not use this model for real decisions. Model output is a clue, not proof.

  • Use only fictional records in this page.
  • Do not enter real student, client, or workplace data.
